# Advance-CGPA-Calculator
The Advanced CGPA Calculator is a client-side web application developed as part of a Web Engineering course project. The system is designed to calculate Semester GPA (SGPA) and Cumulative GPA (CGPA) using a marks-based evaluation system, following the official University of Haripur absolute grading policy.

The application demonstrates core web engineering principles such as separation of concerns, dynamic content generation, DOM manipulation, and event-driven programming, without using any backend or database.

🎯 Objectives
To apply Web Engineering concepts in a real academic problem
To convert a console-based C++ CGPA system into a web-based application
To automate marks-to-grade conversion and reduce manual calculation errors
To implement a dynamic, user-friendly interface using modern web technologies

🧱 System Architecture (Web Engineering Perspective)
This project follows a three-layer client-side architecture:

1️⃣ Presentation Layer (HTML)
Provides the structure of the application
Collects user inputs (student data, semesters, marks, credit hours)
Displays calculated SGPA and CGPA results

2️⃣ Style Layer (CSS)
Handles layout, responsiveness, and visual consistency
Uses grid-based layout for course input organization
Improves usability and readability

3️⃣ Logic Layer (JavaScript)
Implements grading rules and calculation logic
Dynamically generates semesters and courses
Performs real-time GPA and CGPA calculations
Manipulates the DOM to update results without page reload

⚙️ Key Features
Dynamic semester and course generation
Marks-based grading system (automatic grade conversion)
Semester-wise GPA calculation
Overall CGPA calculation
University-compliant grading policy
Client-side processing (no backend required)

JavaScript variables and DOM elements are used for data processing
No database or persistent storage is used
